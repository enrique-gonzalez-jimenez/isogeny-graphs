# Section 8: Determining the Isogeny Graph from the Adelic Galois Representation

This directory contains the SageMath implementation of the algorithm described
in Section 8 of the paper

> Alexander J. Barrios, Enrique González-Jiménez, and Ivan Novak,  
> *Isogeny Graphs of Elliptic Curves in Characteristic Zero*,  
> arXiv:2608.02494 (2026).

- **Paper:** <https://arxiv.org/abs/2608.02494>
- **Main repository:** <https://github.com/enrique-gonzalez-jimenez/isogeny-graphs>

## Main file

```text
image_to_graph_algorithm.sage
```

The program is written for SageMath.

## Mathematical purpose

Let $E$ be an elliptic curve over a field $K$ of characteristic zero satisfying

```math
\mathrm{End}_K(E)\cong\mathbb{Z}.
```

After choosing a compatible system of bases for the torsion subgroups of $E$,
the adelic Galois representation attached to $E$ is

```math
\rho_E:G_K\longrightarrow
\mathrm{GL}_2(\widehat{\mathbb{Z}}),
```

where $G_K=\mathrm{Gal}(\overline{K}/K)$ is the absolute Galois group of $K$.

Theorem 8.1 proves that the image of this representation determines the
pointed edge-weighted isogeny graph

```math
\bigl(\mathcal{G}(E/K),[E]_K\bigr).
```

The code in this directory implements the algorithm appearing in the proof of
that theorem.

## Input

The algorithm takes the following input.

1. A positive integer $n$, equal to the level of the adelic Galois
   representation $\rho_E$.

2. A finite set of matrices

```math
S\subseteq\mathrm{GL}_2(\mathbb{Z}/n\mathbb{Z})
```

   such that, with respect to some basis of $E[n]$,

   ```math
   \rho_{E,n}(G_K)=\langle S\rangle.
   ```

Equivalently, it is enough that the subgroup generated by $S$ be conjugate to
the mod-$n$ Galois image. A change of basis conjugates the matrix group and
does not change the isomorphism class of the resulting pointed graph.

The input consists only of group-theoretic data. An equation for the elliptic
curve is not required.

## Input format

The exact input interface is defined in `image_to_graph_algorithm.sage`.

A typical input consists of:

- the level $n=p^v$;
- a list of invertible $2\times2$ matrices over this ring $\mathbb{Z}/n\mathbb{Z}$; and
- A finite set of matrices ....

Schematically:

```python
R = Integers(3**4)

Sp = [
    Matrix(R, [[1,1 ],[9,1]]),
    Matrix(R, [[1,0],[0,1]]),
    Matrix(R, [[1,0],[0,1]])
]

p_isogeny_graph(3, 4, Sp)

```

The matrices in `generators` must generate the mod-n Galois image, up to
conjugacy.
